Antes de empezar
Contexto, objetivo y preguntas guía

Hasta ahora una app puede guardar información temporal en variables o estados, pero esos datos desaparecen cuando se cierra la aplicación. En esta práctica darás el siguiente paso: guardar información en una base de datos en la nube.

El producto final será una app con una pantalla tipo menú y un formulario de reseñas. Al enviar el formulario, la reseña se guardará como documento dentro de una colección de Firestore.

¿Firestore o Realtime Database?
Lee esto antes de empezar — usaremos Firestore

Firebase ofrece dos bases de datos. Aquí la diferencia en términos simples:

✓ La que usaremos
Cloud Firestore
Guarda datos como documentos (objetos con campos)
Fácil de buscar, filtrar y ordenar
Escala bien cuando la app crece
Opción moderna recomendada por Google
Perfecta para formularios y colecciones
No recomendada
Realtime Database
Guarda todo en un árbol JSON plano
Difícil de consultar con filtros complejos
No recomendada para proyectos nuevos
Diseño más antiguo y limitado
Más difícil de organizar para formularios
¿Por qué Firestore para esta práctica?
Cada reseña se guardará como un documento dentro de una colección llamada resenas. Puedes pensar en una colección como una carpeta y cada documento como un archivo adentro — eso es exactamente lo que Firestore hace.

Crear tu proyecto en Firebase
Pasos en la consola web — hazlo antes de tocar el código
Antes de empezar
Necesitas una cuenta de Google. Abre console.firebase.google.com en tu navegador.
Notas rápidas antes de crear el proyecto
En el plan gratuito, una cuenta de Google normalmente puede crear un número limitado de proyectos de Firebase, aproximadamente entre 5 y 10. Si borras un proyecto, puede tardar varios días en dejar de contar para ese límite. Para esta práctica, conviene reutilizar proyectos de prueba o borrar los que ya no se usen.
Google Analytics no es obligatorio
Para esta práctica solo usaremos Cloud Firestore, así que puedes dejar Google Analytics desactivado. Si aparece la pantalla "Configurar Google Analytics", regresa al paso anterior y desactiva Analytics. No afecta a Firestore ni al código de React Native.
¿Por qué registrar una app Web si usamos React Native?
Con Expo y React Native usamos JavaScript. Firebase nos da la configuración JavaScript desde la opción Web (</>), por eso registramos una app Web aunque después la app se pruebe en Android o iOS con Expo Go. La opción Android se usa más para proyectos nativos con archivos como google-services.json.
Servicios principales de Firebase
Firebase ofrece servicios para crear y operar apps: bases de datos (Firestore, Realtime Database, SQL Connect), autenticación, almacenamiento de archivos, hosting, funciones backend, protección con App Check, notificaciones, analíticas, reportes de errores, pruebas y configuración remota. En esta práctica solo ocuparemos Firestore.

FormularioScreen.jsx — el formulario completo
4 campos + estrellas interactivas + validación + envío a Firestore
Las estrellas interactivas
Usamos 5 botones con el símbolo ★. Al tocar una estrella se guarda ese número en el estado estrellas. Las anteriores se colorean amarillo, las siguientes quedan grises. Sin librerías extra.
¿Dónde se dibujan?
Las 5 estrellas se crean en la Parte 3: JSX y estilos, dentro de [1,2,3,4,5].map(...). Ese recorrido genera un botón por cada número; el estilo star las deja grises y starActive pinta de amarillo las seleccionadas.
📄 screens/FormularioScreen.jsx — Parte 1: imports y estados
import { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity,
  Alert, StyleSheet, ScrollView } from 'react-native';
import { collection, addDoc, serverTimestamp } from 'firebase/firestore';
import { db } from '../firebase';

export default function FormularioScreen() {

  // Un estado por cada campo del formulario
  const [nombre, setNombre] = useState('');
  const [fecha, setFecha] = useState('');
  const [estrellas, setEstrellas] = useState(0);
  const [comentarios, setComentarios] = useState('');
  const [enviando, setEnviando] = useState(false);
📄 screens/FormularioScreen.jsx — Parte 2: función enviar
  // Función que valida y envía los datos a Firestore
  const enviar = async () => {

    // Validar que todos los campos estén llenos
    if (!nombre.trim() || !fecha.trim() || estrellas === 0 || !comentarios.trim()) {
      Alert.alert('Campos incompletos', 'Por favor completa todos los campos.');
      return;
    }

    try {
      setEnviando(true);

      // Guardar documento en la colección "resenas" de Firestore
      await addDoc(collection(db, 'resenas'), {
        nombre: nombre.trim(),
        fecha: fecha.trim(),
        estrellas: estrellas,
        comentarios: comentarios.trim(),
        timestamp: serverTimestamp(),
      });

      Alert.alert('¡Enviado!', 'Tu reseña fue guardada. ¡Gracias!');
      // Limpiar el formulario
      setNombre(''); setFecha(''); setEstrellas(0); setComentarios('');

    } catch (error) {
      Alert.alert('Error', 'No se pudo enviar. Revisa tu conexión.');
    } finally {
      setEnviando(false);
    }
  };
📄 screens/FormularioScreen.jsx — Parte 3: JSX y estilos
  return (
    <ScrollView style={styles.container} contentContainerStyle={styles.content}>

      {/* Campo: Nombre */}
      <Text style={styles.label}>Tu nombre</Text>
      <TextInput style={styles.input} placeholder="Escribe tu nombre completo"
        value={nombre} onChangeText={setNombre} />

      {/* Campo: Fecha */}
      <Text style={styles.label}>Fecha</Text>
      <TextInput style={styles.input} placeholder="dd/mm/aaaa"
        value={fecha} onChangeText={setFecha} keyboardType="numbers-and-punctuation" />

      {/* Campo: Estrellas — 5 botones interactivos */}
      <Text style={styles.label}>Calificación</Text>
      <View style={styles.starsRow}>
        {[1,2,3,4,5].map(i => (
          <TouchableOpacity key={i} onPress={() => setEstrellas(i)}>
            <Text style={[styles.star, i <= estrellas && styles.starActive]}>★</Text>
          </TouchableOpacity>
        ))}
      </View>

      {/* Campo: Comentarios — multiline */}
      <Text style={styles.label}>Comentarios</Text>
      <TextInput style={[styles.input, styles.inputMulti]}
        placeholder="Escribe tu opinión..."
        value={comentarios} onChangeText={setComentarios}
        multiline numberOfLines={4} textAlignVertical="top" />

      {/* Botón de envío */}
      <TouchableOpacity
        style={[styles.boton, enviando && styles.botonDisabled]}
        onPress={enviar} disabled={enviando}
      >
        <Text style={styles.botonTxt}>{enviando ? 'Enviando...' : 'Enviar reseña'}</Text>
      </TouchableOpacity>
    </ScrollView>
  );
}
