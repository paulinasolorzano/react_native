01
¿Por qué no usamos el SDK de Firebase Auth?
Problema de arquitectura en Expo Go — léelo antes de empezar
⚠️ Error que verías si usaras firebase/auth directamente Component auth has not been registered yet — este error ocurre porque Expo Go siempre activa la Nueva Arquitectura de React Native, y el SDK de Firebase Auth requiere módulos nativos que no son compatibles con ella dentro de Expo Go.
Solución que usaremos
Firebase ofrece una API REST para autenticación: en vez de importar el SDK, hacemos una llamada fetch() directa a los servidores de Firebase. Funciona en cualquier entorno porque solo usa JavaScript puro. Para Firestore sí usamos el SDK modular — este no tiene el problema de arquitectura porque usa HTTP internamente.
Nota sobre newArchEnabled Poner newArchEnabled: false en app.json NO soluciona el problema dentro de Expo Go — esa opción solo aplica para builds de producción. En Expo Go siempre estás con la nueva arquitectura.

04
Configurar Metro — paso crítico
Sin esto, Firebase no puede cargar sus módulos correctamente
¿Por qué es obligatorio? Firebase distribuye algunos archivos en formato .cjs (CommonJS). Metro, el bundler de Expo, por defecto no sabe cómo resolverlos. Sin esta configuración verás errores extraños al importar Firebase.

Crea el archivo metro.config.js en la raíz del proyecto:

metro.config.js
const { getDefaultConfig } = require('expo/metro-config');

const config = getDefaultConfig(__dirname);

config.resolver.sourceExts.push('cjs');
config.resolver.unstable_enablePackageExports = false;

module.exports = config;

src/firebase.js
Firestore modular + Auth vía REST
Cómo funciona
Exportamos db (Firestore SDK modular) para leer y escribir datos, y un objeto auth que internamente hace llamadas fetch() a la API REST de Firebase en vez de usar el SDK de Auth.
src/firebase.js
import { initializeApp } from 'firebase/app';
import { getFirestore } from 'firebase/firestore';

const firebaseConfig = {
  apiKey:            "TU_API_KEY",
  authDomain:        "TU_PROYECTO.firebaseapp.com",
  projectId:         "TU_PROYECTO",
  storageBucket:     "TU_PROYECTO.firebasestorage.app",
  messagingSenderId: "TU_SENDER_ID",
  appId:             "TU_APP_ID",
};

const app = initializeApp(firebaseConfig);
export const db = getFirestore(app);

// Auth vía REST (compatible con nueva arquitectura de React Native)
const AUTH_URL = 'https://identitytoolkit.googleapis.com/v1/accounts';
const API_KEY  = firebaseConfig.apiKey;

async function authRequest(endpoint, email, password) {
  const res = await fetch(`${AUTH_URL}:${endpoint}?key=${API_KEY}`, {
    method:  'POST',
    headers: { 'Content-Type': 'application/json' },
    body:    JSON.stringify({ email, password, returnSecureToken: true }),
  });
  const data = await res.json();
  if (!res.ok) throw { code: data.error?.message };
  return { uid: data.localId, email: data.email, token: data.idToken };
}

export const auth = {
  signInWithEmailAndPassword:     (email, pw) =>
    authRequest('signInWithPassword', email, pw),
  createUserWithEmailAndPassword: (email, pw) =>
    authRequest('signUp', email, pw),
};
Sustituye los valores Reemplaza todos los campos de firebaseConfig con los datos reales de tu proyecto Firebase.

src/context/AuthContext.jsx
Compartir el usuario entre todas las pantallas
Context API
El AuthProvider guarda el usuario en un estado de React. Cualquier pantalla que llame a useAuth() puede leer el usuario y cambiar la sesión con setUser.
src/context/AuthContext.jsx
import { createContext, useContext, useState } from 'react';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);

  return (
    <AuthContext.Provider value={{ user, setUser }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  return useContext(AuthContext);
}
08
App.js
Navegación condicional según el estado de sesión
Lógica de navegación
Si user tiene valor → muestra HomeScreen. Si user es null → muestra LoginScreen. El cambio ocurre automáticamente cuando el usuario inicia sesión o cierra sesión.
App.js
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { AuthProvider, useAuth } from './src/context/AuthContext';
import LoginScreen from './src/screens/LoginScreen';
import HomeScreen  from './src/screens/HomeScreen';

const Stack = createNativeStackNavigator();

function Navigator() {
  const { user } = useAuth();

  return (
    <NavigationContainer>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        {user
          ? <Stack.Screen name="Home"  component={HomeScreen} />
          : <Stack.Screen name="Login" component={LoginScreen} />
        }
      </Stack.Navigator>
    </NavigationContainer>
  );
}

export default function App() {
  return (
    <AuthProvider>
      <Navigator />
    </AuthProvider>
  );
}

src/screens/LoginScreen.jsx
Registro e inicio de sesión en una sola pantalla

Un solo estado modo controla si el botón registra o inicia sesión. Al completar el proceso, se llama a setUser(usuario) para guardar el usuario y la navegación cambia automáticamente a HomeScreen.

src/screens/LoginScreen.jsx
import { useState } from 'react';
import {
  View, Text, TextInput, TouchableOpacity,
  StyleSheet, Alert, KeyboardAvoidingView, Platform,
} from 'react-native';
import { auth } from '../firebase';
import { useAuth } from '../context/AuthContext';

export default function LoginScreen() {
  const { setUser } = useAuth();
  const [email,    setEmail]    = useState('');
  const [password, setPassword] = useState('');
  const [modo,     setModo]     = useState('login');
  const [cargando, setCargando] = useState(false);

  async function entrar() {
    if (!email.trim() || !password) {
      Alert.alert('Campos requeridos', 'Ingresa correo y contraseña.');
      return;
    }
    setCargando(true);
    try {
      let usuario;
      if (modo === 'login') {
        usuario = await auth.signInWithEmailAndPassword(
          email.trim(), password
        );
      } else {
        if (password.length < 6) {
          Alert.alert('Contraseña corta', 'Mínimo 6 caracteres.');
          setCargando(false);
          return;
        }
        usuario = await auth.createUserWithEmailAndPassword(
          email.trim(), password
        );
      }
      setUser(usuario);
    } catch (e) {
      Alert.alert('Error', traducir(e.code));
    } finally {
      setCargando(false);
    }
  }

  return (
    <KeyboardAvoidingView
      style={styles.wrap}
      behavior={Platform.OS === 'ios' ? 'padding' : undefined}
    >
      <Text style={styles.titulo}>Reseñas UTM</Text>
      <Text style={styles.subtitulo}>
        {modo === 'login'
          ? 'Inicia sesión para continuar'
          : 'Crea tu cuenta'}
      </Text>

      <TextInput
        style={styles.input}
        placeholder="Correo electrónico"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
      />
      <TextInput
        style={styles.input}
        placeholder="Contraseña"
        value={password}
        onChangeText={setPassword}
        secureTextEntry
      />

      <TouchableOpacity
        style={styles.btn}
        onPress={entrar}
        disabled={cargando}
      >
        <Text style={styles.btnTxt}>
          {cargando
            ? 'Espera…'
            : modo === 'login'
              ? 'Iniciar sesión'
              : 'Crear cuenta'}
        </Text>
      </TouchableOpacity>

      <TouchableOpacity
        onPress={() =>
          setModo(modo === 'login' ? 'registro' : 'login')
        }
      >
        <Text style={styles.link}>
          {modo === 'login'
            ? '¿No tienes cuenta? Regístrate'
            : '¿Ya tienes cuenta? Inicia sesión'}
        </Text>
      </TouchableOpacity>
    </KeyboardAvoidingView>
  );
}

function traducir(code) {
  const m = {
    'EMAIL_EXISTS':            'Este correo ya tiene una cuenta.',
    'INVALID_LOGIN_CREDENTIALS': 'Correo o contraseña incorrectos.',
    'INVALID_EMAIL':           'El correo no es válido.',
    'WEAK_PASSWORD':           'Contraseña de mínimo 6 caracteres.',
    'TOO_MANY_ATTEMPTS_TRY_LATER': 'Demasiados intentos. Espera.',
  };
  return m[code] ?? `Error: ${code}`;
}

Formulario con DateTimePicker + lista en tiempo real
Puntos clave de esta pantalla
DateTimePicker muestra el selector de fecha nativo del sistema. onSnapshot mantiene la lista actualizada en tiempo real sin necesidad de recargar. Cada comentario se guarda con el uid del usuario para que solo vea los suyos.
src/screens/HomeScreen.jsx — imports y estado
import { useState, useEffect } from 'react';

  View, Text, TextInput, TouchableOpacity, StyleSheet,
  Alert, ActivityIndicator, KeyboardAvoidingView,
  Platform, ScrollView,

  collection, addDoc, query, where,
  orderBy, onSnapshot, serverTimestamp,
} from 'firebase/firestore';
import { useAuth } from '../context/AuthContext';

export default function HomeScreen() {
  const { user, setUser } = useAuth();
  const [titulo,      setTitulo]    = useState('');
  const [fecha,       setFecha]     = useState(new Date());
  const [mostrarDP,   setMostrarDP] = useState(false);
  const [estrellas,   setEstrellas] = useState(0);
  const [comentarios, setComentarios] = useState('');
  const [guardando,   setGuardando] = useState(false);
  const [resenas,     setResenas]   = useState([]);
  const [cargando,    setCargando]  = useState(true);
src/screens/HomeScreen.jsx — lógica
  // Escucha en tiempo real los comentarios del usuario actual
  useEffect(() => {
    if (!user) return;
    const q = query(
      collection(db, 'resenas'),
      where('uid', '==', user.uid),
      orderBy('timestamp', 'desc'),
    );
    const unsub = onSnapshot(q, snap => {
      setResenas(snap.docs.map(d => ({ id: d.id, ...d.data() })));
      setCargando(false);
    });
    return unsub; // limpia el listener al salir
  }, [user]);

  function formatFecha(d) {
    return d.toLocaleDateString('es-MX', {
      day: '2-digit', month: 'long', year: 'numeric',
    });
  }

  async function enviar() {
    if (!titulo.trim() || estrellas === 0) {
      Alert.alert('Campos requeridos',
        'Completa el título y la calificación.');
      return;
    }
    setGuardando(true);
    try {
      await addDoc(collection(db, 'resenas'), {
        uid:         user.uid,
        email:       user.email,
        titulo:      titulo.trim(),
        fecha:       formatFecha(fecha),
        estrellas,
        comentarios: comentarios.trim(),
        timestamp:   serverTimestamp(),
      });
      setTitulo(''); setFecha(new Date());
      setEstrellas(0); setComentarios('');
      Alert.alert('Guardado', 'Comentario enviado.');
    } catch (e) {
      Alert.alert('Error', e.message);
    } finally {
      setGuardando(false);
    }
  }

Reglas de Firestore
Firestore → Reglas → Publicar
¿Por qué necesitamos cambiar las reglas? Usamos Auth REST — Firestore no puede verificar automáticamente que el usuario está autenticado. Para una app de práctica configuramos acceso abierto. En una app real se usaría @react-native-firebase con el SDK nativo para tener reglas por usuario.
Firestore → Reglas
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
Después de pegar las reglas Haz clic en Publicar. Las reglas tardan unos segundos en aplicarse.
