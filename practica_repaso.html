App React Native con Expo Go SDK 54

Pantalla principal con 2 cards — componente reutilizable + navegación con estado

Conceptos clave
Componente reutilizable
Recibe props, se usa múltiples veces con distintos datos
Screen
Pantalla completa, puede manejar estado
useState
Hook que controla qué se muestra en pantalla
Props
Datos que el componente padre pasa al hijo
Estructura del proyecto
App.jsx raíz
Punto de entrada. Solo llama a HomeScreen.
screens/HomeScreen.jsx screen
Pantalla principal. Maneja el estado con useState. Renderiza 2 InfoCard.
screens/InfoScreen.jsx screen
Pantalla de detalle. Recibe tipo, contenido y onVolver como props.
components/InfoCard.jsx componente
Card reutilizable hecha con React Native Elements (@rneui/themed).
Pasos de desarrollo
1
Crear el proyecto
Inicializar con Expo
terminal 
npx create-expo-app@latest MiApp --template blank
cd MiApp
2
Configurar .npmrc
Evitar conflictos de dependencias

Crear un archivo .npmrc en la raíz del proyecto con el siguiente contenido:

.npmrc 
legacy-peer-deps=true

Esto evita errores al instalar librerías con conflictos de versiones entre React 19 y dependencias de terceros.

3
Instalar dependencias
React Native Elements + Safe Area
terminal 
npx expo install @rneui/themed @rneui/base react-native-vector-icons
npx expo install react-native-safe-area-context

Siempre usar npx expo install para que Expo resuelva versiones compatibles con SDK 54.

4
Crear components/InfoCard.jsx
Componente reutilizable con @rneui/themed

Este componente recibe 4 props: title, description, color y onPress. Usa Card, Text y Button de @rneui/themed.

components/InfoCard.jsx 
import { StyleSheet } from 'react-native';
import { Card, Text, Button } from '@rneui/themed';

export default function InfoCard({ title, description, color, onPress }) {
  return (
    <Card containerStyle={[styles.card, { borderTopColor: color }]}>
      <Card.Title style={styles.title}>{title}</Card.Title>
      <Card.Divider />
      <Text style={styles.description}>{description}</Text>
      <Button
        title="Ver más"
        buttonStyle={[styles.boton, { backgroundColor: color }]}
        onPress={onPress}
      />
    </Card>
  );
}

const styles = StyleSheet.create({
  card: { borderRadius: 12, borderTopWidth: 4, marginHorizontal: 16, marginVertical: 10 },
  title: { fontSize: 18 },
  description: { fontSize: 14, color: '#555', marginBottom: 16 },
  boton: { borderRadius: 8 },
});
5
Crear screens/InfoScreen.jsx
Pantalla de detalle, sin navegación

No sabe nada de navegación. Solo recibe datos y una función para volver.

screens/InfoScreen.jsx 
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';

export default function InfoScreen({ tipo, contenido, onVolver }) {
  return (
    <View style={styles.container}>
      <Text style={styles.titulo}>{tipo}</Text>
      <Text style={styles.contenido}>{contenido}</Text>
      <TouchableOpacity style={styles.boton} onPress={onVolver}>
        <Text style={styles.botonTexto}>← Volver</Text>
      </TouchableOpacity>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, backgroundColor: '#fff' },
  titulo: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  contenido: { fontSize: 16, color: '#444', lineHeight: 24 },
  boton: { marginTop: 30, backgroundColor: '#4A90E2', padding: 14, borderRadius: 10, alignItems: 'center' },
  botonTexto: { color: '#fff', fontWeight: 'bold', fontSize: 16 },
});
6
Crear screens/HomeScreen.jsx
Lógica central con useState

Aquí vive toda la lógica. seleccion decide qué se muestra en pantalla.

seleccion = null → muestra las 2 cards
Clic en card → setSeleccion('noticias')
seleccion = 'noticias' → muestra InfoScreen con datos
Clic en Volver → setSeleccion(null) → regresa a cards
screens/HomeScreen.jsx 
import { useState } from 'react';
import { View, Text, StyleSheet, SafeAreaView } from 'react-native';
import InfoCard from '../components/InfoCard';
import InfoScreen from './InfoScreen';

const DATA = {
  noticias: { tipo: 'Noticias', contenido: 'Aquí va el contenido de noticias.' },
  eventos:  { tipo: 'Eventos',  contenido: 'Aquí va el contenido de eventos.'  },
};

export default function HomeScreen() {
  const [seleccion, setSeleccion] = useState(null);

  if (seleccion) {
    return (
      <InfoScreen
        tipo={DATA[seleccion].tipo}
        contenido={DATA[seleccion].contenido}
        onVolver={() => setSeleccion(null)}
      />
    );
  }

  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.header}>Bienvenido</Text>
      <Text style={styles.subtitle}>Selecciona una opción</Text>
      <InfoCard
        title="Noticias"
        description="Consulta las últimas noticias del día."
        color="#4A90E2"
        onPress={() => setSeleccion('noticias')}
      />
      <InfoCard
        title="Eventos"
        description="Descubre los próximos eventos."
        color="#E25C4A"
        onPress={() => setSeleccion('eventos')}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  header: { fontSize: 26, fontWeight: 'bold', marginTop: 30, marginLeft: 16 },
  subtitle: { fontSize: 15, color: '#888', marginLeft: 16, marginBottom: 10 },
});

Diferencia clave: screen vs componente
InfoCard — componente reutilizable componente
No tiene estado propio. Solo recibe props y los muestra. Se puede usar 2, 5 o 10 veces con distintos datos. Es como una plantilla.
HomeScreen — screen screen
Tiene estado con useState. Decide qué se muestra. Usa InfoCard dos veces con datos diferentes. Es la "inteligente" de la app.
InfoScreen — screen screen
No tiene estado. Solo muestra lo que le pasa HomeScreen via props. No sabe de navegación, solo recibe datos y los presenta.
