1
¿Qué hace Firebase Authentication?
Conceptos antes de escribir código

Firebase Authentication es un servicio que guarda usuarios, contraseñas (encriptadas) y sesiones en la nube. Tú nunca guardas contraseñas en tu código — Firebase lo hace por ti de forma segura. Solo necesitas llamar a sus funciones y Firebase hace el resto.

🔴 Sin sesión

user = null
Muestra pantallas de Login y Registro

→ signIn / register → ← signOut ←

🟢 Con sesión

user = { email, uid }
Muestra pantalla Home protegida

📌 Punto clave
Firebase recuerda la sesión automáticamente. Si el usuario cierra la app y la vuelve a abrir, sigue con sesión iniciada. Tú solo tienes que escuchar con onAuthStateChanged.
Funciones que usarás
createUserWithEmailAndPassword
→ Crea una cuenta nueva
signInWithEmailAndPassword
→ Inicia sesión
signOut
→ Cierra sesión
onAuthStateChanged
→ Escucha cambios de sesión
Lo que Firebase devuelve
user.email — correo del usuario
user.uid — ID único en Firebase
user.displayName — nombre (si lo pones)
user.emailVerified — si verificó su correo
null — si no hay sesión activa

Instalar y configurar Authentication
Agregar auth a firebase.js
Instala Firebase. En Expo siempre usa npx expo install en lugar de npm install — así Expo elige la versión compatible con tu SDK:
npx expo install firebase
⚠️ Importante — no uses npm install directamente
npm install firebase puede instalar una versión incompatible con tu versión de Expo SDK. npx expo install siempre elige la versión correcta automáticamente.
Actualiza tu firebase.js para exportar también auth:
firebase.js
import { initializeApp } from 'firebase/app';
import { getFirestore } from 'firebase/firestore';
import { getAuth } from 'firebase/auth';    // ← línea nueva

const firebaseConfig = {
  apiKey: "TU_API_KEY",
  authDomain: "TU_PROYECTO.firebaseapp.com",
  projectId: "TU_PROYECTO",
  storageBucket: "TU_PROYECTO.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123:web:abc"
};

const app = initializeApp(firebaseConfig);
export const db   = getFirestore(app);
export const auth = getAuth(app);    // ← exportar auth
💡 Tip
El auth que exportas es la instancia de Authentication. La pasarás a todas las funciones de login, registro y logout.
5
Crear el AuthContext
Para compartir el usuario en toda la app sin pasar props

El Context es una forma de guardar información que cualquier pantalla puede leer sin que se la pasen como prop. Lo usaremos para guardar el usuario actual y saber si hay sesión activa.

🧠 ¿Por qué Context y no useState en App.js?
Si guardas el usuario solo en App.js, tendrías que pasarlo como prop a todas las pantallas (user={user}). Con Context, cualquier pantalla lo lee directamente con useContext. Más limpio y escalable.
src/context/AuthContext.jsx
import { createContext, useContext, useState, useEffect } from 'react';
import { onAuthStateChanged } from 'firebase/auth';
import { auth } from '../firebase';

// 1. Crear el contexto (caja vacía que compartiremos)
const AuthContext = createContext(null);

// 2. El Provider envuelve toda la app y provee el usuario
export function AuthProvider({ children }) {
  const [user, setUser] = useState(undefined); // undefined = cargando

  useEffect(() => {
    // onAuthStateChanged escucha si el usuario abre/cierra sesión
    // Firebase lo llama automáticamente al abrir la app también
    const unsub = onAuthStateChanged(auth, (usuario) => {
      setUser(usuario); // null si no hay sesión, objeto si sí
    });
    return unsub; // limpia el listener al desmontar
  }, []);

  return (
    <AuthContext.Provider value={{ user }}>
      {children}
    </AuthContext.Provider>
  );
}

// 3. Hook para leer el usuario desde cualquier pantalla
export function useAuth() {
  return useContext(AuthContext);
}
⚠️ user = undefined vs null
undefined = aún no sabemos (Firebase está verificando). Muestra una pantalla de carga.
null = Firebase confirmó que NO hay sesión. Muestra Login.
objeto = hay sesión activa. Muestra Home.
6
App.js — Navegación según sesión
Si hay usuario → Home. Si no → Login/Registro
App.js
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { AuthProvider, useAuth } from './src/context/AuthContext';
import LoginScreen from './src/screens/LoginScreen';
import RegistroScreen from './src/screens/RegistroScreen';
import HomeScreen from './src/screens/HomeScreen';
import { ActivityIndicator, View } from 'react-native';

const Stack = createNativeStackNavigator();

function AppNavigator() {
  const { user } = useAuth();

  // Mientras Firebase verifica la sesión, mostramos carga
  if (user === undefined) {
    return (
      <View style={{ flex:1, justifyContent:'center', alignItems:'center' }}>
        <ActivityIndicator size="large" />
      </View>
    );
  }

  return (
    <NavigationContainer>
      <Stack.Navigator>
        {user ? (
          // Con sesión: solo puede ir al Home
          <Stack.Screen name="Home" component={HomeScreen} />
        ) : (
          // Sin sesión: Login y Registro
          <>
            <Stack.Screen name="Login" component={LoginScreen} />
            <Stack.Screen name="Registro" component={RegistroScreen} />
          </>
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
}

export default function App() {
  return (
    <AuthProvider>
      <AppNavigator />
    </AuthProvider>
  );
}
💡 Patrón importante
El Navigator cambia de pantallas automáticamente cuando cambia user. Si el usuario cierra sesión, Firebase llama a onAuthStateChanged con null, el contexto actualiza user, y el Navigator muestra Login instantáneamente. No necesitas navegar manualmente.

RegistroScreen.jsx
Crear cuenta nueva con correo y contraseña
src/screens/RegistroScreen.jsx
import { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity, StyleSheet, Alert } from 'react-native';
import { createUserWithEmailAndPassword } from 'firebase/auth';
import { auth } from '../firebase';

export default function RegistroScreen({ navigation }) {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [cargando, setCargando] = useState(false);

  async function registrar() {
    if (!email || !password) {
      Alert.alert('Error', 'Ingresa correo y contraseña');
      return;
    }
    setCargando(true);
    try {
      await createUserWithEmailAndPassword(auth, email, password);
      // onAuthStateChanged detecta el nuevo usuario automáticamente
      // y App.js muestra HomeScreen — no necesitas navegar aquí
    } catch (error) {
      Alert.alert('Error al registrar', traducirError(error.code));
    } finally {
      setCargando(false);
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.titulo}>Crear cuenta</Text>
      <TextInput style={styles.input} placeholder="Correo electrónico"
        value={email} onChangeText={setEmail}
        keyboardType="email-address" autoCapitalize="none" />
      <TextInput style={styles.input} placeholder="Contraseña (mín. 6 caracteres)"
        value={password} onChangeText={setPassword} secureTextEntry />
      <TouchableOpacity style={styles.btn} onPress={registrar} disabled={cargando}>
        <Text style={styles.btnTxt}>{cargando ? 'Creando cuenta…' : 'Registrarse'}</Text>
      </TouchableOpacity>
      <TouchableOpacity onPress={() => navigation.navigate('Login')}>
        <Text style={styles.link}>¿Ya tienes cuenta? Inicia sesión</Text>
      </TouchableOpacity>
    </View>
  );
}

// Traduce los códigos de error de Firebase a mensajes en español
function traducirError(code) {
  const errores = {
    'auth/email-already-in-use': 'Este correo ya tiene una cuenta.',
    'auth/invalid-email': 'El correo no es válido.',
    'auth/weak-password': 'La contraseña debe tener al menos 6 caracteres.',
  };
  return errores[code] || 'Ocurrió un error. Intenta de nuevo.';
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 24, backgroundColor: '#f4f7f8' },
  titulo: { fontSize: 24, fontWeight: 'bold', marginBottom: 24, color: '#263f4d' },
  input: { backgroundColor: '#fff', borderWidth: 1.5, borderColor: '#e2e8f0', borderRadius: 10, padding: 12, marginBottom: 12, fontSize: 15 },
  btn: { backgroundColor: '#315567', borderRadius: 10, padding: 14, alignItems: 'center', marginBottom: 12 },
  btnTxt: { color: '#fff', fontWeight: 'bold', fontSize: 15 },
  link: { color: '#315567', textAlign: 'center', textDecorationLine: 'underline', fontSize: 13 },
});

LoginScreen.jsx
Iniciar sesión con cuenta existente
📌 Nota
La estructura es casi idéntica a RegistroScreen. La única diferencia es la función de Firebase que se llama.
src/screens/LoginScreen.jsx
import { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity, StyleSheet, Alert } from 'react-native';
import { signInWithEmailAndPassword } from 'firebase/auth';
import { auth } from '../firebase';

export default function LoginScreen({ navigation }) {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [cargando, setCargando] = useState(false);

  async function iniciarSesion() {
    if (!email || !password) {
      Alert.alert('Error', 'Ingresa tu correo y contraseña');
      return;
    }
    setCargando(true);
    try {
      await signInWithEmailAndPassword(auth, email, password);
      // App.js detecta el cambio y muestra Home automáticamente
    } catch (error) {
      Alert.alert('Error al iniciar sesión', traducirError(error.code));
    } finally {
      setCargando(false);
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.titulo}>Bienvenido</Text>
      <TextInput style={styles.input} placeholder="Correo electrónico"
        value={email} onChangeText={setEmail}
        keyboardType="email-address" autoCapitalize="none" />
      <TextInput style={styles.input} placeholder="Contraseña"
        value={password} onChangeText={setPassword} secureTextEntry />
      <TouchableOpacity style={styles.btn} onPress={iniciarSesion} disabled={cargando}>
        <Text style={styles.btnTxt}>{cargando ? 'Verificando…' : 'Iniciar sesión'}</Text>
      </TouchableOpacity>
      <TouchableOpacity onPress={() => navigation.navigate('Registro')}>
        <Text style={styles.link}>¿No tienes cuenta? Regístrate</Text>
      </TouchableOpacity>
    </View>
  );
}

function traducirError(code) {
  const errores = {
    'auth/user-not-found': 'No existe cuenta con este correo.',
    'auth/wrong-password': 'Contraseña incorrecta.',
    'auth/invalid-email': 'El correo no es válido.',
    'auth/too-many-requests': 'Demasiados intentos. Espera un momento.',
    'auth/invalid-credential': 'Correo o contraseña incorrectos.',
  };
  return errores[code] || 'Ocurrió un error. Intenta de nuevo.';
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 24, backgroundColor: '#f4f7f8' },
  titulo: { fontSize: 24, fontWeight: 'bold', marginBottom: 24, color: '#263f4d' },
  input: { backgroundColor: '#fff', borderWidth: 1.5, borderColor: '#e2e8f0', borderRadius: 10, padding: 12, marginBottom: 12, fontSize: 15 },
  btn: { backgroundColor: '#315567', borderRadius: 10, padding: 14, alignItems: 'center', marginBottom: 12 },

HomeScreen.jsx — Pantalla protegida + Logout
Solo accesible cuando hay sesión activa
src/screens/HomeScreen.jsx
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';
import { signOut } from 'firebase/auth';
import { auth } from '../firebase';
import { useAuth } from '../context/AuthContext';

export default function HomeScreen() {
  const { user } = useAuth();  // leemos el usuario del Context

  async function cerrarSesion() {
    await signOut(auth);
    // onAuthStateChanged se activa → user = null → App.js muestra Login
  }

  return (
    <View style={styles.container}>
      <Text style={styles.avatar}>👤</Text>
      <Text style={styles.saludo}>¡Hola!</Text>
      <Text style={styles.email}>{user?.email}</Text>
      <Text style={styles.info}>
        Esta pantalla solo se muestra{'\n'}a usuarios con sesión activa.
      </Text>
      <TouchableOpacity style={styles.btnLogout} onPress={cerrarSesion}>
        <Text style={styles.btnLogoutTxt}>Cerrar sesión</Text>
      </TouchableOpacity>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24, backgroundColor: '#edf5f6' },
  avatar: { fontSize: 64, marginBottom: 12 },
  saludo: { fontSize: 22, fontWeight: 'bold', color: '#263f4d', marginBottom: 4 },
  email: { fontSize: 13, color: '#94a3b8', marginBottom: 20 },
  info: { fontSize: 13, color: '#475569', textAlign: 'center', lineHeight: 22, marginBottom: 32 },
  btnLogout: { borderWidth: 2, borderColor: '#dc2626', borderRadius: 10, padding: 13, width: '100%', alignItems: 'center' },
  btnLogoutTxt: { color: '#dc2626', fontWeight: 'bold', fontSize: 15 },
});
✅ Magia de onAuthStateChanged
Al llamar signOut(auth), Firebase notifica al listener en AuthContext, user se vuelve null, y App.js muestra automáticamente el Login. El usuario nunca puede volver a Home sin autenticarse de nuevo.

🔍 ¿Qué es el UID?
El uid es el identificador único de cada usuario en Firebase. Si guardas datos en Firestore que pertenecen a un usuario específico, usa user.uid como clave del documento para que solo ese usuario pueda leerlos.
