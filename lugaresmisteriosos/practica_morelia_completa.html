Lugares Misteriosos de Morelia

App React Native con cards, imágenes, Stack Navigator, Bottom Tab y Drawer. Componentes reutilizables con React Native Elements.

React Native Expo Go SDK 54 @rneui/themed Stack Navigator Bottom Tab Drawer
Conceptos que usaremos

React Native

Framework para crear apps móviles con JavaScript. El código se convierte en componentes nativos de iOS y Android.

Expo Go SDK 54

Con Expo Go en tu celular puedes ver la app en tiempo real escaneando un QR. Siempre crear proyectos con --template blank@sdk-54.

Componente reutilizable

Un componente que recibe props y se puede usar N veces con distintos datos. En esta app es LugarCard.

React Navigation

Librería para navegar entre pantallas. Usaremos Stack (apila pantallas), Tab (barra inferior) y Drawer (menú lateral).

React Native Elements

Librería de componentes visuales listos: Card, Button, Text con estilos incluidos.

route.params

Cómo pasar datos de una pantalla a otra al navegar. Se envían con navigate() y se reciben con route.params.

App de lugares misteriosos de Morelia, Michoacán.

React Native + Expo Go SDK 54
Estructura de navegación

La app tiene 3 niveles de navegación anidados:

NivelNavigatorQué hacePantallas que contiene
1 (externo) Drawer Menú lateral que se abre deslizando desde la izquierda Tab Navigator, AcercaScreen
2 (intermedio) Bottom Tab Barra de pestañas en la parte inferior del celular Stack Navigator, MapaScreen, FavoritosScreen
3 (interno) Stack Apila pantallas. El botón ← te regresa a la anterior HomeScreen, DetalleScreen
En resumen: el Drawer envuelve al Tab, el Tab contiene al Stack, y el Stack maneja la navegación entre la lista de cards y el detalle de cada lugar.

Orden recomendado: .npmrc → instalar librerías → data.js → LugarCard → screens → App.js
Pasos
1
Crear el proyecto con SDK 54
Siempre usar --template blank@sdk-54
Importante: siempre crear el proyecto con --template blank@sdk-54. Sin esto se instala SDK 56 y no será compatible con Expo Go.
terminal
npx create-expo-app@latest LugaresMorelia --template blank@sdk-54
cd LugaresMorelia

Verifica que se instaló SDK 54 correctamente:

verificar versión
cat package.json | grep '"expo"'
# debe mostrar: "expo": "~54.0.34"
2
Crear .npmrc antes de instalar
Evitar errores de compatibilidad

Crea el archivo .npmrc en la raíz del proyecto con este contenido:

.npmrc
legacy-peer-deps=true
Crea este archivo ANTES de instalar cualquier librería. Le dice a npm que ignore los conflictos de versiones entre librerías y React 19.

Crea también las carpetas:

terminal
mkdir screens components assets assets/images
3
Instalar librerías
React Native Elements + Stack + Tab + Drawer
Siempre usa npx expo install — resuelve automáticamente versiones compatibles con SDK 54.
1 — React Native Elements
npx expo install @rneui/themed @rneui/base react-native-vector-icons
npx expo install react-native-safe-area-context
2 — React Navigation base
npx expo install @react-navigation/native
npx expo install react-native-screens react-native-safe-area-context
3 — Stack Navigator
npx expo install @react-navigation/native-stack
4 — Bottom Tab Navigator
npx expo install @react-navigation/bottom-tabs
5 — Drawer Navigator
npx expo install @react-navigation/drawer
npx expo install react-native-gesture-handler react-native-reanimated

Componente LugarCard.jsx
components/LugarCard.jsx — card reutilizable

Recibe un objeto lugar y una función onPress. Se usa 5 veces en HomeScreen, una por cada lugar.

components/LugarCard.jsx
import { StyleSheet, TouchableOpacity, Image } from 'react-native';
import { Card, Text } from '@rneui/themed';

export default function LugarCard({ lugar, onPress }) {
  return (
    <TouchableOpacity onPress={onPress} activeOpacity={0.85}>
      <Card containerStyle={styles.card}>
        <Image source={lugar.imagen} style={styles.imagen} />
        <Card.Title>{lugar.nombre}</Card.Title>
        <Card.Divider />
        <Text style={styles.descripcion}>{lugar.descripcion}</Text>
      </Card>
    </TouchableOpacity>
  );
}

const styles = StyleSheet.create({
  card: { borderRadius: 12, padding: 0, overflow: 'hidden', marginBottom: 16 },
  imagen: { width: '100%', height: 180, resizeMode: 'cover' },
  descripcion: { fontSize: 13, color: '#555', lineHeight: 20, marginBottom: 8 },
});

screens/HomeScreen.jsx
Lista de cards — pantalla inicial del Stack

Muestra todos los lugares con FlatList. Al dar clic en una card llama a navigation.navigate('Detalle', { lugar: item }) para ir a la pantalla de detalle.

screens/HomeScreen.jsx
import { FlatList, StyleSheet, SafeAreaView, Text } from 'react-native';
import LugarCard from '../components/LugarCard';
import lugares from '../data';

export default function HomeScreen({ navigation }) {
  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.titulo}>Lugares Misteriosos</Text>
      <Text style={styles.subtitulo}>Morelia, Michoacán</Text>
      <FlatList
        data={lugares}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <LugarCard
            lugar={item}
            onPress={() => navigation.navigate('Detalle', { lugar: item })}
          />
        )}
        contentContainerStyle={{ padding: 16 }}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  titulo: { fontSize: 24, fontWeight: 'bold', marginTop: 20, marginLeft: 16 },
  subtitulo: { fontSize: 14, color: '#888', marginLeft: 16, marginBottom: 8 },
});

App.js — configurar toda la navegación
Stack + Bottom Tab + Drawer en un solo archivo

Se crean 3 funciones anidadas: InicioStack dentro de MisTabs dentro de App con el Drawer.

La primera línea debe ser import 'react-native-gesture-handler' — si no está, el Drawer no funcionará.
App.js
import 'react-native-gesture-handler'; // debe ser la primera línea
import { NavigationContainer }        from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { createBottomTabNavigator }   from '@react-navigation/bottom-tabs';
import { createDrawerNavigator }      from '@react-navigation/drawer';

import HomeScreen      from './screens/HomeScreen';
import DetalleScreen   from './screens/DetalleScreen';
import MapaScreen      from './screens/MapaScreen';
import FavoritosScreen from './screens/FavoritosScreen';
import AcercaScreen    from './screens/AcercaScreen';

const Stack  = createNativeStackNavigator();
const Tab    = createBottomTabNavigator();
const Drawer = createDrawerNavigator();

// 1. Stack: Home → Detalle
function InicioStack() {
  return (
    <Stack.Navigator>
      <Stack.Screen name="Home"    component={HomeScreen}
        options={{ title: 'Lugares Misteriosos' }} />
      <Stack.Screen name="Detalle" component={DetalleScreen}
        options={({ route }) => ({ title: route.params.lugar.nombre })} />
    </Stack.Navigator>
  );
}

// 2. Tab: Inicio | Mapa | Favoritos
function MisTabs() {
  return (
    <Tab.Navigator
      screenOptions={{ tabBarActiveTintColor: '#4A90E2', tabBarInactiveTintColor: '#aaa', headerShown: false }}
    >
      <Tab.Screen name="Inicio"    component={InicioStack}     />
      <Tab.Screen name="Mapa"      component={MapaScreen}      />
      <Tab.Screen name="Favoritos" component={FavoritosScreen} />
    </Tab.Navigator>
  );
}

// 3. Drawer: Tabs | Acerca de
export default function App() {
  return (
    <NavigationContainer>
      <Drawer.Navigator screenOptions={{ headerShown: false }}>
        <Drawer.Screen name="Principal" component={MisTabs}      options={{ title: 'Inicio' }}     />
        <Drawer.Screen name="Acerca"    component={AcercaScreen} options={{ title: 'Acerca de' }} />
      </Drawer.Navigator>
    </NavigationContainer>
  );
}
