📦 Concepto 1 — ¿Qué es useState?

Cuando quieres que tu pantalla recuerde un valor y se actualice sola cuando ese valor cambia, usas useState. Es la forma que tiene React de decir: "guarda esto, y cada vez que cambie, redibuja la pantalla automáticamente".

🌡️ Analogía — El termostato

Imagina el display de un termostato. Muestra 20°. Si lo cambias a 25° presionando el botón, el display se actualiza solo.

El display es tu variable de estado — lo que ves en pantalla.
El botón es la función set — la única manera válida de cambiar el valor.
La actualización automática es lo que hace React: cuando llamas al botón, redibuja el componente.

Si intentaras cambiar el display con un marcador (modificando la variable directo), el termostato no funcionaría. En React es lo mismo: nunca cambies el valor directo, usa siempre la función set.

La sintaxis siempre devuelve dos cosas en un arreglo:

const [valor, setValor] = useState(valorInicial);
Parte¿Qué es?Ejemplo concreto
valorLa variable que lees y muestras en pantalla. React la recuerda entre renders.query — el texto del buscador
setValorLa función para cambiar el valor. Al llamarla, React redibuja el componente.setQuery('morelia')
valorInicialEl valor con el que empieza cuando aparece el componente por primera vez.'' — cadena vacía

La diferencia crítica entre una variable normal y una de estado:

❌ Variable normal — No funciona
let texto = '';

// El usuario escribe "morelia"
texto = 'morelia';

// React NO sabe que cambió.
// La lista NO se actualiza.
// La pantalla queda congelada.
✅ useState — Sí funciona
const [texto, setTexto] = useState('');

// El usuario escribe "morelia"
setTexto('morelia');

// React SÍ sabe que cambió.
// La lista se filtra sola.
// La pantalla se redibuja.
👨‍👧 Concepto 2 — Componentes padre e hijo

Cuando un componente usa a otro componente adentro, el que contiene es el padre y el que está adentro es el hijo. En esta app ya tienes esta relación desde la Práctica 1: CatalogScreen renderiza varias PlaceCard.

🏠 Analogía — La casa y sus habitaciones

CatalogScreen es la casa completa. Dentro hay varias PlaceCard, como habitaciones — una por cada lugar turístico.

La casa (padre) sabe cuántas habitaciones tiene, cuáles son favoritas y qué texto escribió el usuario. Ella es la que guarda la información importante.

Cada habitación (hijo) solo muestra lo que la casa le dijo. No puede ver las otras habitaciones ni cambiar la lista de favoritos por su cuenta.

Para que una habitación avise algo a la casa ("¡el usuario tocó favorito aquí!"), necesita un timbre que la casa le instaló. Ese timbre es el callback.

📬 Concepto 3 — ¿Qué son las Props?

Props son los datos que el padre le entrega al hijo. Viajan en una sola dirección: del padre hacia el hijo. El hijo las recibe, las usa para mostrarse, pero no puede cambiarlas.

👨‍🍳 Analogía — El chef y el mesero

El padre (CatalogScreen) es el chef que prepara los ingredientes: sabe qué lugares hay, cuáles son favoritos y qué escribió el usuario.

El hijo (PlaceCard) es el mesero que recibe el plato ya preparado y solo lo lleva a la mesa. El mesero no decide los ingredientes — solo presenta lo que recibió.

En la Práctica 2 ya pasabas la prop place: <PlaceCard place={item} />. En esta práctica agregarás dos props nuevas: isFavorite y onToggleFav.

// El padre pasa datos al hijo mediante props:
<PlaceCard
  place={item}              // prop de datos: el objeto del lugar
  isFavorite={true}        // prop booleana: ¿está en favoritos?
  onToggleFav={miFuncion}   // prop función: el "timbre" (callback)
/>

// El hijo las recibe desestructuradas en sus parámetros:
export default function PlaceCard({ place, isFavorite, onToggleFav }) {
  // Aquí puede usar place.name, isFavorite, onToggleFav...
}
🔔 Concepto 4 — ¿Qué es un Callback?

Un callback es una función que el padre le pasa al hijo como prop, para que el hijo la llame cuando ocurra un evento. Es la única forma que tiene el hijo de comunicarle algo al padre, ya que las props solo van de padre a hijo.

🔔 Analogía — El timbre de la habitación

La casa (padre) instala un timbre en cada habitación (hijo). Cuando el usuario toca ❤️ en una PlaceCard, la tarjeta presiona ese timbre.

La casa escucha el timbre y decide: "¡Ah, marcaron favorito el lugar con id '2'! Voy a actualizar mi lista."

La habitación no sabe qué hace la casa cuando suena el timbre. Solo sabe que debe presionarlo y pasarle el ID del lugar. Eso es un callback.

// PADRE — Define la función y se la da al hijo
const toggleFavorite = (id) => {
  // Cuando el hijo llame a esta función, recibirá el id del lugar
  setFavorites(prev =>
    prev.includes(id) ? prev.filter(x => x !== id) : [...prev, id]
  );
};

// El padre le instala el timbre al hijo:
<PlaceCard onToggleFav={toggleFavorite} ... />


// HIJO — Recibe el timbre y lo presiona cuando el usuario toca ❤️
export default function PlaceCard({ place, isFavorite, onToggleFav }) {
  return (
    <TouchableOpacity onPress={() => onToggleFav(place.id)}>
      {/* El hijo NO sabe qué pasa después — solo llama la función */}
      <Text>{isFavorite ? '❤️' : '🤍'}</Text>
    </TouchableOpacity>
  );
}

screens/CatalogScreen.js — modificado

Se agregan: el estado query para el buscador, el estado favorites para los IDs favoritos, la función callback toggleFavorite y un botón para ir a la pantalla de favoritos.

import React, { useState } from 'react';
import { View, Text, FlatList, TextInput, TouchableOpacity, StyleSheet } from 'react-native';
import { useNavigation } from '@react-navigation/native';
import { places } from '../data/places';
import PlaceCard from '../components/PlaceCard';

export default function CatalogScreen() {
  const navigation = useNavigation();

  // ── Estado 1: texto del buscador
  // Inicia como cadena vacía. Cuando el usuario escribe, se actualiza
  const [query, setQuery] = useState('');

  // ── Estado 2: arreglo con los IDs de los lugares favoritos
  // Inicia como arreglo vacío. Se llena cuando el usuario toca ❤️
  const [favorites, setFavorites] = useState([]);

  // ── Lista filtrada: se recalcula en cada render según el valor de query
  // NO necesita ser estado porque se deriva del array original + query
  const filtered = places.filter(p =>
    p.name.toLowerCase().includes(query.toLowerCase())
  );

  // ── Callback que PlaceCard llamará cuando el usuario toque ❤️
  // Recibe el id del lugar y decide si agregarlo o quitarlo de favorites
  const toggleFavorite = (id) => {
    setFavorites(prev =>
      prev.includes(id)
        ? prev.filter(fid => fid !== id)  // ya estaba → quitar
        : [...prev, id]                       // no estaba → agregar
    );
  };

  return (
    <View style={styles.container}>

      {/* ── Encabezado con título y botón de favoritos */}
      <View style={styles.headerRow}>
        <View>
          <Text style={styles.header}>Explore Mich</Text>
          <Text style={styles.subtitle}>Catálogo turístico de Michoacán</Text>
        </View>

        {/* Botón para navegar a FavoritesScreen, pasando los IDs y los datos */}
        <TouchableOpacity
          style={styles.favBadge}
          onPress={() =>
            navigation.navigate('Favorites', { favoriteIds: favorites })
          }
        >
          <Text style={styles.favBadgeText}>❤️ {favorites.length}</Text>
        </TouchableOpacity>
      </View>

      {/* ── Buscador controlado por el estado query */}
      <TextInput
        style={styles.search}
        placeholder="🔍 Buscar lugar..."
        value={query}
        onChangeText={setQuery}
      />

      {/* ── Lista: usa filtered (no el array completo) */}
      <FlatList
        data={filtered}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <PlaceCard
            place={item}
            isFavorite={favorites.includes(item.id)}
            onToggleFav={toggleFavorite}
          />
        )}
        contentContainerStyle={styles.list}
      />
    </View>
  );
}

components/PlaceCard.js — modificado

Recibe dos props nuevas del padre: isFavorite (dato) y onToggleFav (callback). No guarda ningún estado propio.

import React from 'react';
import { Text, Image, TouchableOpacity, StyleSheet } from 'react-native';
import { Card, Button, Icon } from '@rneui/themed';
import { useNavigation } from '@react-navigation/native';

// Nuevas props recibidas del padre:
//   isFavorite  → booleano: true si el lugar está en favoritos
//   onToggleFav → callback: función del padre que se llama al tocar ❤️
export default function PlaceCard({ place, isFavorite, onToggleFav }) {
  const navigation = useNavigation();

  return (
    <Card containerStyle={styles.card}>
      <Image source={{ uri: place.image }} style={styles.image} />

      {/* Botón de favorito — al presionar llama al callback del padre con el id */}

      >
        {/* Muestra ❤️ si isFavorite es true, 🤍 si es false */}

      <Text style={styles.category}>{place.category}</Text>

        title="Ver más"
        icon={<Icon name="map" type="feather" color="white" size={18} />}
        buttonStyle={styles.button}
        onPress={() => navigation.navigate('Detail', { place })}
      />
    </Card>
  );
}

screens/FavoritesScreen.js — NUEVO

Tercera pantalla. Recibe los IDs favoritos por route.params y usa useState localmente para el buscador interno. Filtra los lugares originales para mostrar solo los que están en la lista de favoritos.

import React, { useState } from 'react';
import {
  View, Text, FlatList, Image,
  TextInput, TouchableOpacity, StyleSheet
} from 'react-native';
import { useNavigation } from '@react-navigation/native';
import { places } from '../data/places';

export default function FavoritesScreen({ route }) {
  // Recibe los IDs favoritos que CatalogScreen envió al navegar
  const { favoriteIds } = route.params;

  // ── Estado local: buscador dentro de favoritos
  const [query, setQuery] = useState('');

  const navigation = useNavigation();

  // Paso 1: filtrar el array completo para quedarse solo con los favoritos
  const favoritePlaces = places.filter(p => favoriteIds.includes(p.id));

  // Paso 2: sobre esos favoritos, aplicar el buscador local
  const filtered = favoritePlaces.filter(p =>
    p.name.toLowerCase().includes(query.toLowerCase())
  );

  // Vista cuando no hay ningún favorito marcado aún
  if (favoriteIds.length === 0) {
    return (
      <View style={styles.empty}>
        <Text style={styles.emptyIcon}>🤍</Text>
        <Text style={styles.emptyTitle}>Sin favoritos todavía</Text>
        <Text style={styles.emptySubtitle}>
          Regresa al catálogo y toca ❤️ en los lugares que te interesen.
        </Text>
        <TouchableOpacity
          style={styles.backBtn}
          onPress={() => navigation.goBack()}
        >
          <Text style={styles.backBtnText}>← Volver al catálogo</Text>
        </TouchableOpacity>
      </View>
    );
  }

  return (
    <View style={styles.container}>

      {/* Contador de favoritos */}
      <Text style={styles.count}>
        {favoriteIds.length} lugar{favoriteIds.length !== 1 ? 'es' : ''} guardado{favoriteIds.length !== 1 ? 's' : ''}
      </Text>

      {/* Buscador local — useState propio de esta pantalla */}
      <TextInput
        style={styles.search}
        placeholder="🔍 Buscar en tus favoritos..."
        value={query}
        onChangeText={setQuery}
      />

      <FlatList
        data={filtered}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <TouchableOpacity
            style={styles.card}
            onPress={() => navigation.navigate('Detail', { place: item })}
          >
            <Image source={{ uri: item.image }} style={styles.cardImage} />
            <View style={styles.cardInfo}>
              <Text style={styles.cardCategory}>{item.category}</Text>
              <Text style={styles.cardName}>{item.name}</Text>
              <Text style={styles.cardDesc}>{item.description}</Text>
              <Text style={styles.cardLink}>Ver detalle →</Text>
            </View>
          </TouchableOpacity>
        )}
        contentContainerStyle={{ paddingBottom: 30 }}
        ListEmptyComponent={
          <Text style={styles.noResults}>
            Sin resultados para "{query}"
          </Text>
        }
      />
    </View>
  );
}

🚀 Retos opcionales
Reto 1 — Quitar favorito desde FavoritesScreen

El problema: si el usuario desmarca un favorito en CatalogScreen, los cambios no se reflejan en FavoritesScreen porque los IDs se pasan como params fijos al navegar. Investiga React Context o pasa una función callback también a FavoritesScreen para que pueda actualizar el estado del padre.

Reto 2 — Contador de favoritos en el header

Muestra el número de favoritos directamente en el título del header de CatalogScreen. Pista: usa options dinámico en el Stack.Screen o el hook useLayoutEffect.

Reto 3 — Filtro por categoría

Agrega un segundo estado categoria con botones tipo chip para filtrar por "Todos", "Zona arqueológica", "Pueblo artesanal", etc. Combínalo con el estado query para que ambos filtros funcionen al mismo tiempo.
